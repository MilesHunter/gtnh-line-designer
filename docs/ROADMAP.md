## PNG 整图导出（Canvas 2D）

状态：规划中，未排期。

### 背景

0.2.0 的 PNG 导出使用 `html-to-image` 克隆画布 DOM，24 MB 的 `atlas.webp` 会被逐个图标内联成 base64，导出时卡死。当前已改为 `webContents.capturePage` 导出当前视图，解决了卡死，但分辨率和取景范围受窗口限制。整条产线、固定高分辨率、可取消的导出需要改为 Canvas 2D 自绘。

### 目标

- 导出整个产线，不受当前视口、缩放和窗口大小影响。
- 固定输出尺寸，默认长边 4096，可按设置调整。
- 500 节点、1,000 条边的验收规模下可完成导出，并显示进度、支持取消。
- 不克隆 DOM，不把整张图集内联进样式。
- 导出期间不阻塞界面交互。

### 实现要点

- 用 `getNodesBounds` 计算全图边界，用 `getViewportForBounds` 计算画布尺寸与偏移。
- Canvas 2D 绘制节点卡片、文字、端口和图标；图标直接 `drawImage(atlas, sx, sy, 32, 32, dx, dy, 32, 32)` 裁剪，复用当前 data v7 图集。
- 边复用 React Flow 的 `getSmoothStepPath` 生成路径，再通过 `new Path2D(d)` 描边。
- 绘图与 PNG 编码可放入 Worker/OffscreenCanvas；至少保证 PNG 编码不阻塞渲染主线程。
- 导出范围提供“当前视图 / 整个产线”两个选项，默认整个产线。
- 统一空状态、选中态和“结果已过期”标记的绘制规则，避免与屏幕显示不一致。

### 验收标准

- 10、100、500 节点三档产线均能导出，图标、连线、文字与画布一致。
- 输出长边不超过配置上限，内存峰值可控。
- 导出中可取消；取消或失败后画布状态、缩放和选择保持不变。
- 不再出现 24 MB 级资源被复制到每个图标的情况。

### 风险

- 需要复刻节点卡片的视觉细节，字体换行和像素图标缩放是主要工作量。
- 导出范围与虚拟化渲染不一致时，需要以项目数据为准，而不是以当前 DOM 为准。
- 在整图导出稳定前，保留 `capturePage` 作为“当前视图”导出路径。
