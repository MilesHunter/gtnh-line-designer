# GTNH Line Designer 0.3.0

本次更新把机器选择、画布排版和 PNG 导出一起做了收尾：单方块按机器族合并，机器类型区分单/多/巨，新增一键自动排版，并修复导出 PNG 时软件卡死。

## 机器选择

- 单方块的电压变体合并为一个机器族：搜索“离心机”只会看到一个单方块入口，基础、进阶、精英等级由节点电压决定。
- 机器明确区分单方块、多方块和巨型多方块，节点与候选卡片显示“单 / 多 / 巨”。
- 从配方搜索选定具体机器后立即收起机器列表，直接创建已配置节点，不再重复选择。
- 检查器默认只显示已选机器摘要，需要主动点击“更换机器”才展开下拉框。

## 画布与排版

- 顶部新增“自动排版”：按物料流方向从左到右分层，减少节点重叠和连线交叉。
- 自动排版按节点高度和端口数量计算间距，整次移动合并为一步撤销。
- 节点连线改为带圆角的折线路径，长距离产线和扇入扇出更容易追踪。

## PNG 导出

- 修复导出 PNG 时软件卡死：不再用 DOM 克隆把 24 MB 图集逐个图标内联，改为 Electron 原生截屏。
- 导出期间隐藏 MiniMap、缩放控件和空状态提示，只保留画布内容。
- 当前导出为当前视图、窗口原生分辨率；整图和高分辨率导出已列入后续规划。

## 兼容性

- 0.1.0 / 0.2.0 的 `.gtnhgraph` 项目继续可用，旧格式打开时自动迁移。
- Release 仍不包含任何 GTNH 配方数据；首次使用需在线下载 data v7，或从本机实例执行 NESQL 导入。
- 便携包解压到可写目录即可运行，数据、项目、设置和日志保存在程序目录，不写入 `%APPDATA%`。

Windows x64 便携包：`GTNH-Line-Designer-0.3.0-portable-x64.zip`。
