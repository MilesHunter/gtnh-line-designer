# GTNH Line Designer 0.2.0

本次更新把原来的“配方节点”重构为更贴近游戏实际的“机器节点”，并集中处理了搜索、计算流程、本地数据兼容和大型产线性能问题。

## 机器节点重构

- 每台具体机器作为一个节点，区分单方块与多方块。
- 可以先放置空机器节点，再在右侧检查器中选择该机器支持的配方。
- 同一条配方可由多台机器执行时，左侧会明确列出具体机器，由玩家选择。
- 节点采用左输入、右产物两列布局，默认折叠多余端口，可在节点内展开。
- 机器名称中文优先，已知机器支持中英文搜索；缺少译名时安全显示原名。
- 右侧配方搜索绑定当前机器，直接点击配方即可配置，不再重复选择机器。

## 搜索与数据兼容

- 左侧拆分“机器搜索”和“原料 / 产物搜索”。
- 原料/产物通过具体物品、流体或矿辞芯片精确匹配；两边同时填写时取交集。
- 配方结果按机器类别折叠分组，不显示时间与能耗摘要，优先突出原料、产物和可用机器。
- 单方块/多方块识别同时支持英文与中文 NESQL tooltip，已经导出的 2.8.4 和 2.9.0 本地数据无需重新导出。
- 升级便携目录时可以直接复制整个 `data` 目录，继续使用已有缓存。
- 旧版 `.gtnhgraph` 项目自动迁移到机器节点格式；缺失配方和机器会保留并标记。

## 计算流程

- 节点实时显示理论输入、输出、功率、建议机器数和负载率。
- 整线计算仍由“计算”按钮触发，不会随编辑自动执行。
- 电压低于配方基础等级时节点无效；超频只由超过基础电压触发。
- 线圈只对支持线圈的多方块机器开放，并行按具体机器规则计算。
- 计算前校验整图，无效节点高亮并阻止求解。
- 计算使用可取消的阶段进度弹窗，完成后自动关闭。
- 修改配置后保留上一次结果并标记“已过期”，避免误把旧流量当成新结果。

## 性能与稳定性

- 以 500 节点、1,000 条边作为交互验收规模。
- 画布只渲染可见节点，拖动时只替换被移动的节点对象。
- 单节点预览按变化节点批量发送到 Worker，避免整图重复计算。
- 撤销历史改为节点和边的增量记录，不再为每一步复制整张项目。
- 修复中文本地数据机器类型全部显示为多方块的问题。
- 不兼容物料在连线阶段直接拒绝，悬空连线在计算前静默清理。

## 数据与发布说明

- Release 不包含 `data.bin.gz`、`atlas.webp` 或任何 GTNH 配方数据包。
- 数据可在线下载，或通过本机 NESQL 导出后导入。
- 本机导出数据只适用于对应的整合包版本、模组集合和配置。

Windows x64 便携包解压到任意可写目录即可运行。核心数据、设置、项目与日志都保存在程序目录，不写入 `%APPDATA%`。
